# Simulador de papel personalizado — Papel Para Mechas

Página do simulador: https://grupoi9adailton-cmyk.github.io/simulador-ppm/

O cliente envia a logo, vê os 3 modelos do papel na folha de aprovação da PPM, escolhe um, aprova e envia o PDF do modelo aprovado para a PPM.

Arquivo gerado pelo projeto interno da PPM (pasta ppm_cliente, `python3 build.py <versão>`). Não editar o index.html à mão: gerar de novo e substituir.
Versão publicada: v0.5 (12/11/2026).
